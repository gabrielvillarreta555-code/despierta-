# Despierta

Aplicación Android de alarmas con repetición semanal, sonidos, modo oscuro,
posponer/detener y funcionamiento sobre la pantalla bloqueada.

## Generar el APK desde un teléfono

1. Crea una cuenta o inicia sesión en [GitHub](https://github.com).
2. Crea un repositorio nuevo y sube el contenido de este proyecto.
3. Abre la pestaña **Actions** del repositorio.
4. Entra en **Generar APK** y pulsa **Run workflow**.
5. Cuando finalice, abre la ejecución y descarga **Despierta-APK** en Artifacts.
6. Descomprime el archivo descargado e instala `app-debug.apk`.

Android puede pedir permiso para instalar aplicaciones desde el navegador o el
gestor de archivos. Después de instalar, concede notificaciones y alarmas exactas.
